# Source documents

These are the original project documents, kept here unchanged.

| File | What it is |
|---|---|
| `URITP Guidebook - Google Docs.pdf` | **The single source of truth** for syntax, types, units, error codes (E1xx to R7xx), the instruction set (section 9.2) and the conformance rules (section 9.3). |
| `URITP - Google Docs.pdf` | Six example programs (arm, office rover, drone, quadruped, humanoid, welding arm). |
| `ELARA_URITP_Project_Brief_Book.pdf` | The project brief: goals and background. |

If an example program disagrees with the Guidebook, the Guidebook wins.
Each such decision is written down in `spec/DECISIONS.md`.

Do not edit these PDFs. Our own cleaned-up versions live in `spec/` and `examples/`.
